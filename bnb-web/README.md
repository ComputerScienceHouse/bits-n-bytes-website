# Bits 'n Bytes Website

It's the Bits 'n Bytes website.


## Setup

This site uses vite. run the following commands once setting up environment variables.
```
cd bnb-web
npm run dev
```

## Environment Variables
Follow the template.
```
VITE_PUBLIC_API_AUTH=
VITE_PUBLIC_API_ENDPOINT=

VITE_SSO_CLIENT_ID=
VITE_SSO_AUTHORITY=
VITE_SSO_ENABLED=true
VITE_API_PREFIX=http://localhost:8080
```
